# معمار «أساس»

وثيقة مرجعية لكيفية تركيب التطبيق: الطبقات، نموذج البيانات، خط إنتاج التقرير، وقرارات التصميم.

---

## 1. الفكرة العامة

واجهة ويب (Vite + جافاسكربت خالص بلا إطار عمل) مغلّفة بـ Capacitor 7 لأندرويد.
الذكاء الاصطناعي بمزوّدين يختار الطالب بينهما: OpenRouter بنماذجه المجانية (واجهة متوافقة مع OpenAI عبر fetch)،
أو Claude عبر مكتبة Anthropic الرسمية (`@anthropic-ai/sdk`) — كلاهما من داخل الجهاز مباشرة (ولـ Claude خادم وسيط اختياري).
والصور من واجهات ويكيميديا وOpenverse المفتوحة، والتصدير إلى Word بمكتبة `docx`.

```
┌──────────────────────────────────────────────────────────────┐
│ screens/   home · browse · create · report · library · settings │
├──────────────────────────────────────────────────────────────┤
│ report/    pipeline · compose (دون اتصال) · md · render · covers · sheets   │
│ ai/        client (موحّد) · openrouter · claude · prompts   images/ sources · pipeline │
│ search/    محرك البحث العربي            export/  docx · cover-docx · text     │
├──────────────────────────────────────────────────────────────┤
│ data/      types (12) · categories (5) · universities (3) · topics (120) · kb (120) │
│ core/      store · db (IndexedDB) · arabic · dom · ui · nav · native · fmt   │
├──────────────────────────────────────────────────────────────┤
│ Capacitor: App (زر الرجوع) · Filesystem · Share · PrinterPlugin (يدوية)     │
└──────────────────────────────────────────────────────────────┘
```

## 2. البيانات

التطبيق موجّه لطلبة **المرحلة الثانية** في أقسام الهندسة المدنية (جامعة بغداد، جامعة كربلاء، الجامعة التكنولوجية)
ولموادها الخمس: مقاومة المواد، الرياضيات الهندسية، تكنولوجيا الخرسانة، المساحة، ميكانيك الموائع.

### أنواع التقارير — `data/types.js`
١٢ نوعًا جامعيًا. لكل نوع: اسم، وصف، وقائمة أقسام ثابتة `{ h: العنوان, g: إرشاد المحتوى, k: حقول قاعدة المعرفة }`،
واسم القسم الذي يحمل الخطوات المرقّمة، وعدد الصور الافتراضي، و`readings` إن كان يعتمد على قراءات الطالب
(مختبر، حقلي، أجوبة المناقشة، مشروع). وللقسم خياران إضافيان:
- `only: [مواد]` قسم خاص بمواد بعينها، مثل «المواصفة المعتمدة» في مختبرات الخرسانة والمقاومة فقط.
- `opt: true` قسم لا يناسب كل المواضيع (مثل «الأنواع والحالات» أو «مثال محلول» لموضوع وصفي):
  يكتبه الذكاء الاصطناعي إن كان له مضمون، ويُحذف من التقرير المبني دون اتصال إن لم تتوفر مادته، ولا يُعدّ ناقصًا.

`sectionsOf(type, cat)` تعيد أقسام النوع لمادة معيّنة، وهي المصدر الوحيد للهيكل في الكتابة والتأليف وتخطيط الصور.

### المواد والجامعات — `data/categories.js` و`data/universities.js`
المواد الخمس مع أسمائها المختصرة والإنجليزية ومرادفاتها للبحث. والجامعات الثلاث مع الكلية والقسم؛
`academicYear()` تحسب السنة الدراسية (تبدأ في أيلول) لتظهر في الغلاف.

### العناوين — `data/topics.js`
١٢٠ صفًّا مختصرًا: `[المعرّف، العنوان، الإنجليزية، الأنواع المقترحة، الكتابة الدارجة]`، ويُستنتج منها
`kind`: تجربة مختبر (`lab`) أو عمل حقلي (`field`) أو موضوع نظري (`theory`). الإنجليزية تُستعمل للبحث عن الصور،
والكتابة الدارجة تجمع ما يكتبه الطلبة فعلًا («تنشن»، «سلمب»، «فينشوري»…) والأخطاء الشائعة.

### قاعدة المعرفة — `data/kb/`
محتوى كامل للعناوين الـ١٢٠ بحقول موحّدة:
`intro, obj, theory[], std, app/equip, mat, steps, calc{eq,vars,example,note}, table, graph, limits, notes,
disc[{q,a}], examples[{q,s,a}], defs, kinds, compare{cols,rows}, choose, given{cols,rows}, pros, problems, uses, readings, img`.

| الملف | المحتوى |
|---|---|
| `concrete.js` · `aggregates.js` | تجارب الإسمنت والركام والخرسانة |
| `concrete_extra.js` | مواضيع الخرسانة النظرية، و`SUPPLEMENT` يضيف النظرية وأسئلة المناقشة والقراءات لتجارب الخرسانة |
| `strength.js` · `strength_theory.js` | تجارب مقاومة المواد ومواضيعها النظرية |
| `fluids.js` · `survey.js` · `math.js` | الموائع والمساحة والرياضيات |
| `compare.js` · `theory_extra.js` | جداول المقارنة وخطوات الاختيار ومعطيات المشاريع، والتعاريف والأنواع للتقارير النظرية |

`index.js` يدمجها في `KB` ويعرّف `CAT_REFS` (الكتب المنهجية لكل مادة) ونصوصًا عامة. استعمالان:
1. **التأليف دون اتصال** (`report/compose.js`): كل قسم يأخذ أول حقل متاح من قائمة `k` الخاصة به ولم يُستعمل في قسم سابق،
   والقسم الاختياري الفارغ يُحذف، وما بقي دون مادة يصبح إرشادًا بين `[ ]`.
2. **تأريض الذكاء الاصطناعي** (`ai/prompts.js → kbBrief`): ملخّص مضغوط يُرسل مع الطلب «اعتمد عليها ولا تخالف أرقامها»،
   ويشمل أسئلة المناقشة وأجوبتها والأمثلة المحلولة.

## 3. خط إنتاج التقرير — `report/pipeline.js`

```
startGeneration(report, mode)            mode: ai | offline | images
 ├─ الكتابة ───────────────┐            (بالتوازي)
 │  ai: streamText → splitSections كل 120ms → عرض حي
 │  offline: composeOffline(kb)
 └─ الصور ─────────────────┘
    planFigures   (ai: JSON منظَّم | offline: kb.img)
    findCandidates → acceptable() → verifyLoadable()   ← تنزيل وفك حقيقي
    jsonCall(رؤية): يختار المطابق أو -1                 ← لا صورة خاطئة
    storeCandidate → IndexedDB (Blob + المصدر والرخصة)
```

- المهمة النشطة محفوظة في الذاكرة (`jobs`)؛ إن غادر المستخدم الشاشة وعاد، تشترك من جديد وتكمل العرض.
- إن أُغلق التطبيق أثناء الإنشاء، يُعلَّم التقرير «غير مكتمل» عند فتحه مع زر إعادة المحاولة.
- الصور مرتبطة بالقسم **بعنوانه** (`secTitle`) لا برقمه فقط، فتبقى في مكانها لو تغيّر ترتيب الأقسام؛
  وتخطيط الصور دون اتصال لا يضع صورة في قسم اختياري سيُحذف.
- **قراءات الطالب** (`options.readings`) تُرسل في الطلب تحت «قراءات الطالب الفعلية» ليضعها النموذج في الجداول كما هي
  ويحسب منها؛ وفي غيابها يكتب قيمًا نموذجية بين `[ ]` ومثالًا موصوفًا بأنه توضيحي.
- **الغلاف**: `coverLines(report)` في `report/model.js` مصدر واحد لأسطر الغلاف في العرض وPDF وWord
  (ترويسة الوزارة، الجامعة والكلية والقسم، «تقرير مختبر … — التجربة رقم (n)»، الطالب والمرحلة والشعبة والمشرف، السنة الدراسية).

### المعادلات — `core/mathconv.js` و`core/math.js` و`core/mathjax.js`
الطلبة اشتكوا من معادلات مطبوعة بـ«/» وأقواس متداخلة. الحل طبقتان:
- **المحوّل** (`mathconv.js`، بلا متصفح فيُختبر في Node): محلّل لفظي ونحوي صغير يحوّل `σ = P / A0` إلى
  `\sigma = \frac{P}{A_{0}}`. القسمة كسر دائمًا: البسط سلسلة الضرب إلى اليسار، والمقام الحدّ التالي مع ما يجاوره بلا عملية
  (`V² / 2g` ← `\frac{V^2}{2g}`)، والمشتقة لا تأخذ ما قبلها (`EI·d²y/dx²` ← `EI\cdot\frac{d^2y}{dx^2}`)، والصيغة العلمية عدد واحد
  (`/ 1.0 × 10⁻⁶`). المعرّفات: `fcu` ← `f_{cu}`، `σmax` ← `\sigma_{\max}`، `C3S` و`Al2O3` صيغ كيميائية قائمة، `BHN` و`Re` أسماء قائمة،
  `dx` تفاضل، `nπx` ضرب، والوحدات بعد الأرقام قائمة. سطر المعادلة يُقسَّم إلى تسمية عربية ومعادلات وفواصل (← ، ؛) وشرح بين قوسين،
  والعربي لا يدخل المعادلة إلا داخل `\text{}` كلمة واحدة. داخل الجمل تُكتشف القطع غير العربية التي فيها علاقة أو قسمة أو أس،
  ويُستبعد الوحدات وحدها والتواريخ ورموز المواصفات. LaTeX الجاهز من الذكاء الاصطناعي (`$…$`، ```eq) يُرسم كما هو بعد تحويل أي «/» إلى `\frac`.
- **الرسم** (`mathjax.js`، ملف منفصل يُحمَّل في وقت الفراغ): MathJax ← SVG بوحدات em يتبع حجم الخط ولونه ويُطبع متجهيًّا،
  والنص داخل `\text` يُكتب كلمة واحدة بخط النظام (`mtextFont`) ويُقاس بلوحة رسم حتى تتصل الحروف العربية.
  لـ Word: PNG بدقة ×3 يُنزل بعمق المعادلة ليقع خط أساسها على خط الكتابة، والأسطر التي فيها كسور مسافتها «على الأقل» حتى لا تُقص؛
  أو `export/omml.js` يحوّل شجرة MathML إلى معادلات Word (`m:f`، `m:rad`، `m:sSub`، `m:nary`…) وما لا يُدعم يبقى صورة.

### الأسلوب واللغة والتنسيق — `report/style.js` و`report/format.js`
- `options.level` (طالب عادي/متميّز/أكاديمي)، `options.human` (كتابة طبيعية: تعليمات للنموذج ثم `humanize()` بعد التوليد
  تحذف العبارات القالبية والشرطات الاعتراضية و«» والتشكيل والعريض الزائد دون مسّ المعادلات والجداول والمصادر)،
  `options.lang` (mix/ar/en؛ الإنجليزي يقلب الورقة وWord إلى LTR ويترجم الغلاف ويُعطي عناوين أقسام إنجليزية من `EN_HEADINGS`)،
  و`options.structure` (fixed/free: عناوين يختارها النموذج حسب الموضوع، فلا تُقارن بهيكل النوع).
- `report.format` يغلب `state.format` يغلب `FORMAT_DEFAULTS`. في العرض والطباعة سمات `data-*` ومتغيرات CSS؛ إطار الطباعة
  عنصر ثابت يتكرر على كل صفحة داخل منطقة المحتوى، والمحتوى يبتعد عنه بحشوة `box-decoration-break: clone`. في Word حدود
  صفحة حقيقية لقسم المحتوى، وحجم الخط والمسافة والمحاذاة والعناوين والترقيم والترويسة والتذييل من التنسيق نفسه.
- `formatControls` يعدّل مسودة، ولا يُحفظ شيء إلا بزر «حفظ التغييرات». اللون يُطبَّق على العناوين والترقيم والإطار
  (`--frame`، وعلى الشاشة `--hc` ممزوجًا بلون الورقة ليبقى مقروءًا في الوضع الداكن)، ولون الكتابة `--doc-ink` في الطباعة وWord.
  الإطارات الـ١٢ في `BORDERS` ولكل منها نمط `w:pgBorders` في Word؛ والموجي في الطباعة صورة SVG عبر `border-image`.
  `secNumber()` يكتب رقم القسم بالنمط المختار في العرض والفهرس وWord.
- **التنويع**: `options.variant` من 1 إلى 12 (عشوائي عند الإنشاء). `synonym()` يختار مرادفًا لاسم كل قسم، و`variantRules()`
  يعطي النموذج أسلوبًا مختلفًا للمقدمة والخاتمة، والمؤلّف دون اتصال يغيّر صياغة الخاتمة وشكلها وجملة المقدمة وترتيب القوائم.
- **المحتوى**: `options.lists` (mix/few/none) و`options.tables` تُعطى للنموذج تعليماتٍ، ثم `applyContent()` يضمنها بعد التوليد:
  القوائم تصير فقرات («أولًا… ثم…») والجداول جملًا، دون مسّ المعادلات والمصادر. الصور بعدد صفر، والترقيم في `report.format`.

### العرض التقديمي — `export/pptx.js`
pptxgenjs بشرائح 16:9: عنوان (الجهة، العنوان، النوع، الطلبة، المشرف)، محتويات، شريحة لكل قسم بنقاط مختصرة (تُكمل في شريحة
«تابع» إن طالت)، والمعادلات صور PNG، والجداول جداول حقيقية، وشريحة لكل صورة مع تعليقها، ونص القسم كاملًا في ملاحظات المتحدث،
ثم «شكرًا لحسن الاستماع». اتجاه كل فقرة `rtl` في العربية.

### الغلاف — `report/covers.js` و`report/cover-deco.js` و`export/cover-docx.js`
سبعة عشر نمطًا تُبنى كلها من `coverData(report)`: التسعة الأصلية، وثمانية حديثة (ملكي، شريط مزدوج، لوحة العنوان، عصري، أمواج،
هندسي، لوحة هندسية، زوايا مزخرفة) أعدنا رسمها من تصاميم أغلفة تقارير أنشأناها في Canva (أخذنا التخطيط والأشكال والألوان،
لا صور Canva نفسها، حتى تُملأ ببيانات الطالب وتبقى قابلة للتعديل في Word). مع أسماء طلبة المجموعة (`meta.students`) ولقب المشرف
(`meta.supTitle`) وشعار الكلية (`meta.logo2`)، وبالإنجليزية كاملًا إن كان التقرير إنجليزيًا (المادة ونوع التقرير ورقم التجربة):
- **اللون**: `meta.coverColor` (اسم من `COVER_COLORS` أو أي `#rrggbb`، وإلا لون المادة) و`meta.coverAccent` اللون الثاني.
  `reportColor()` مصدر واحد للغلاف وPowerPoint ولون «الغلاف» في التنسيق (الإطار والعناوين).
- **الحقول**: `meta.hide` (الوزارة، الجامعة، الكلية، القسم، الشعارات، نوع التقرير، المادة، رقم التجربة، الطلبة، المرحلة، المشرف،
  التواريخ، السنة) و`meta.labels` (عنوان مخصّص، والسلسلة الفارغة تعني بلا عنوان). `coverLines()` و`labelsOf()` في
  `report/model.js` تطبّقهما، فيتطابق العرض وWord وPowerPoint. `coverDesign(m)` واجهة واحدة لصفحة الإنشاء وتعديل الغلاف والإعدادات.
- **الزخارف**: `decoSVG(style)` أشكال عند حواف صفحة 794×1123 فقط (أشرطة، أمواج، مثلثات، زوايا، شبكة)، تنعكس للعربية.
  في العرض SVG خلف المحتوى، وفي Word صورة PNG بحجم الصفحة خلف النص (`behindDoc`) من الرسم نفسه، والهوامش تُبعد النص عنها.
- **العرض وPDF**: صفحة بنسب A4 (`aspect-ratio: 210/297`) بخطوط بوحدات `cqw`، فالمعاينة والعرض والطباعة متطابقة. الألوان
  متغيرات CSS ‏`--cc` و`--ca`، و`print-color-adjust: exact` يطبع الأشرطة الملوّنة.
- **Word**: الغلاف قسم مستقل بلا ترويسة ولا تذييل، ويبدأ ترقيم الصفحات من 1 في القسم التالي. الإطار المزدوج حدود صفحة
  حقيقية (`w:pgBorders`)، والأشرطة واللوحات خلايا جداول مظلّلة، وجدول المعلومات جدول Word حقيقي.
- الغلاف اختياري لكل تقرير (`options.cover`)، والنمط والشعار في `meta`، والافتراضي من الإعدادات. التقرير بلا غلاف يبدأ بعنوانه.

### الاستمرار عند الخروج من التطبيق — `core/keepalive.js` و`KeepAlivePlugin.java`
- **أندرويد**: `holdAwake()` يشغّل خدمة أمامية (`KeepAliveService`، نوع dataSync) بإشعار «أساس يكتب…» وقفل إيقاظ جزئي
  ما دام التوليد جاريًا، فلا يجمّد النظام التطبيق ولا يقطع شبكته حين يخرج الطالب منه؛ و`release()` يوقفها ويُظهر «التقرير جاهز»
  إن انتهى والتطبيق في الخلفية. صفحة WebView بأولوية `RENDERER_PRIORITY_IMPORTANT` حتى وهي غير ظاهرة.
- **في كل مكان**: انقطاع الشبكة أثناء البث صار `ORError(kind: 'network')` عابرًا، و`retryTransient()` ينتظر رجوع المستخدم
  (`visibilitychange` و`appStateChange`) وعودة الاتصال ثم يعيد. كتابة التقرير تحتفظ بما كُتب حتى آخر فقرة كاملة
  (`keepWritten`) وتطلب التكملة من بعده (`continuePrompt`) ثم تصلها دون تكرار العنوان (`joinContinuation`).

## 4. الذكاء الاصطناعي — `ai/`

`ai/client.js` واجهة موحّدة (`streamText`, `jsonCall`, `testConnection`, `aiErrorMessage`) تختار المزوّد حسب
`state.ai.provider`؛ بقية التطبيق لا يعرف أي مزوّد يعمل. المستخدمون الذين حفظوا مفتاح Claude قبل إضافة OpenRouter يبقون على Claude.

### OpenRouter — `ai/openrouter.js`

| الجانب | التنفيذ |
|---|---|
| قائمة النماذج | `GET /api/v1/models` حيّة كل 12 ساعة (ونسخة محفوظة دون اتصال)؛ تُصفّى المجانية (`:free` أو تسعير صفري) القادرة على المحادثة، وتُستبعد مصنِّفات الأمان والتضمين وتوليد الصور، وتُرتَّب بالعائلة والحجم والسياق |
| البدائل | كل طلب يحمل `models` بثلاثة: المختار أو الأفضل، ثم نموذج من عائلة أخرى، ثم الموجّه `openrouter/free`؛ والسياق أقل من 16 ألف رمز لا يدخل السلسلة |
| الكتابة | بث SSE: تُتجاهل تعليقات `: OPENROUTER PROCESSING` وتُعرض مرحلة «يفكّر»، والخطأ أثناء البث (`error` و`finish_reason: error`) يُلتقط، و`<think>…</think>` يُحذف، ومهلة توقف دقيقتان |
| JSON | `response_format` بمخطط صارم إن دعمه النموذج (`structured_outputs`) أو وضع JSON، مع قراءة متسامحة (علامات \`\`\`، شرح قبل JSON، فواصل زائدة) ومطابقة متسامحة للمخطط ومحاولة إصلاح واحدة |
| الصور | `image_url` بـ data URL، ونموذج يرى الصور، ومراجعة كل صورتين (3 مرشحات لكل منهما) في طلب |
| الأخطاء | 401 مفتاح، 402 رصيد سالب، 403 فلتر محتوى، 404 قيود الخصوصية للنماذج المجانية أو نموذج اختفى، 429 حد الدقيقة أو اليوم أو ازدحام المزوّد، 5xx — كلها برسائل عربية |
| أندرويد | إن منع WebView الطلب يُعاد عبر `CapacitorHttp` الأصلي (بلا بث) ويُتذكّر ذلك للجلسة |
| اختبار الاتصال | `GET /api/v1/key` ثم طلب JSON صغير فعلي يكشف قيود الخصوصية والحصة |

### DeepSeek بربط الحساب — `ai/oauth.js`
`state.ai.provider = 'deepseek'` يستعمل طبقة OpenRouter نفسها، لكن `chainFor('text')` لا يضع في السلسلة إلا نماذج DeepSeek
(من القائمة الحيّة أو `DEEPSEEK_FALLBACK`). الربط OAuth PKCE: `startLink()` يولّد verifier ويفتح
`openrouter.ai/auth?callback_url=…&code_challenge=…&code_challenge_method=S256`، وعند الرجوع بـ `?code=` يستدعي `main.js`
`handleCallback()` الذي يبادل الرمز بمفتاح عبر `POST /api/v1/auth/keys` ويحفظه ويعيد تحميل الصفحة. في أندرويد
`server.allowNavigation` يسمح بفتح صفحة الدخول داخل التطبيق. لا يوجد لـ DeepSeek نفسه تسجيل دخول للطرف الثالث، فلا يُحاكى موقعه.

### Claude — `ai/claude.js`

كل طلبات Claude تبنيها `buildParams`:

| المعامل | القيمة | السبب |
|---|---|---|
| `model` | `claude-opus-5-5` افتراضيًا (Sonnet 5.5 / Haiku 5.5 اختيارًا) | الأدق للمحتوى الفني |
| `thinking` | `{ type: "adaptive" }` | النموذج يقرر مقدار التفكير |
| `output_config.effort` | من الإعدادات للكتابة (`high` افتراضيًا)، و`low` للمهام البسيطة | توازن الدقة والكلفة |
| `system` | نص ثابت تمامًا مع `cache_control` | تخزين مؤقت يخفّض الكلفة |
| `fallbacks: "default"` + `server-side-fallback-2026-07-01` | لـ Opus وSonnet | إعادة الطلب تلقائيًا عند رفض أمني خاطئ |
| `max_tokens` | 64000 للكتابة المتدفقة، 16000 لطلبات JSON | لا قطع للنص |

أنواع الطلبات:
- **كتابة التقرير**: متدفقة (`client.beta.messages.stream`)، نص Markdown مقيَّد (## للأقسام، ```eq للمعادلات، `[ ]` لما يحتاج تعديلًا). تُجمع الأجزاء بأنفسنا لأن التحويل لنموذج بديل يبدأ كتلة نصية جديدة.
- **تخطيط الصور، اقتراح العناوين، التحقق البصري، اختبار الاتصال**: مخرجات منظَّمة (`output_config.format` بمخطط JSON).
- **تحرير قسم**: متدفق بجهد أقل درجة.

الأخطاء تُترجم إلى رسائل عربية حسب نوعها (`aiErrorMessage`): مفتاح خاطئ، رصيد غير كافٍ، حد الطلبات، الخادم مشغول، لا اتصال، رفض.

## 5. البحث — `search/` و`core/arabic.js`

- توحيد الكتابة: أ/إ/آ ← ا، ى ← ي، ة ← ه، إزالة التشكيل والتطويل، الأرقام العربية ← لاتينية.
- تجذيع خفيف (ال، وال، بال… ات، ون، ين، ية…) ومرادفات عامية ← الصيغة المعتمدة.
- مطابقة: تامة ← بادئة ← مسافة ليفنشتاين (1 أو 2 حسب الطول).
- **وزن IDF**: الكلمات الشائعة («فحص») أخف من النادرة («هطول»)، فـ«فحص السلمب» تعطي فحص الهطول وحده لا كل الفحوصات.
- الكتابة الدارجة بالحروف العربية للمصطلحات الإنجليزية مرادفات للصيغة المعتمدة: «تنشن» ← شد، «كمبريشن» ← انضغاط، «تست» ← فحص…
- كلمات النوع («مختبر»، «ملخص»، «مقارنة»، «مناقشة») تُكتشف لاختيار نوع التقرير وتُحذف من مطابقة العناوين،
  وأسماء المواد ومرادفاتها تُكتشف (`searchSubjects`) لتُعرض المادة المطابقة.

## 6. التصدير

- **Word** (`export/docx.js`): فقرات `bidirectional` ومقاطع `rightToLeft` بخط عربي للحروف المركبة (Simplified Arabic افتراضيًا)،
  جداول `visuallyRightToLeft`، الترقيم يُكتب نصًا صريحًا (يظهر صحيحًا في Word وWPS وLibreOffice وGoogle Docs)،
  صور مضمّنة من IndexedDB مع التعليق والمصدر، غلاف مستقل بلا ترويسة، ورقم صفحة في التذييل.
- **PDF**: نمط `@media print` في `styles/app.css` (غلاف بصفحة، فهرس، منع انقسام الصور والجداول).
  في المتصفح `window.print()`، وفي أندرويد إضافة `PrinterPlugin` تطبع WebView الحالي عبر `PrintManager`
  (لأن `window.print` لا يعمل داخل WebView) فيظهر خيار «حفظ بتنسيق PDF».
- **المشاركة والحفظ**: `@capacitor/share` و`@capacitor/filesystem` في أندرويد، والتنزيل في المتصفح.

مشكلة أخرى عولجت: خانة المفتاح كانت تعتمد على حدث `input` الذي لا تُطلقه بعض لوحات مفاتيح أندرويد عند اللصق،
وكان `captureInput` في إعداد Capacitor يستعمل اتصال إدخال بدائيًا؛ أُلغي، وصارت الخانة تُقرأ وتُنظَّف قبل كل استعمال.

مشكلة شائعة عولجت: النص اللاتيني بين قوسين في جملة عربية «(Deflection of Beams)» تنقلب أقواسه في آخر السطر
أو تتكسّر إذا التفّ السطر داخله؛ `bidi()` تضمّنه باتجاه من اليسار لليمين (LRE … PDF) في العرض وفي Word.

## 7. الفحص — `tools/check.mjs` و`tools/mocks.mjs`

متصفح Chromium بلا واجهة مع محاكيات تعترض الشبكة:
- **Claude**: يرد بتدفق SSE حقيقي الشكل (thinking ثم text) وبـ JSON حسب المخطط المطلوب، ويرفض المفتاح الذي فيه `bad` بـ 401،
  ويسجّل لكل طلب أي مخالفة لإرشادات الواجهة (النموذج، adaptive، effort، fallbacks، cache_control، رأس الوصول من المتصفح).
- **ويكيميديا/ويكيبيديا/Openverse**: نتائج تتضمن عمدًا شعارًا وصورة صغيرة ورابطًا معطوبًا (404) للتأكد من استبعادها،
  والتحقق البصري المحاكى يرفض آخر صورة للتأكد من أنها لا تُعرض.
- ملف Word الناتج يُفحص بـ python-docx: نسبة الفقرات RTL، عدد الصور، الجداول، التعليقات، غلاف الجامعة وترويسة الوزارة.
- محاكي Claude يحتفظ بآخر طلب كتابة ليتأكد الفحص أن قراءات الطالب وصلت إلى النموذج.
- **OpenRouter**: قائمة نماذج فيها مدفوع ومصنِّف أمان وموجّه، و`/key`، وبث فيه تعليقات وأفكار وعناوين بصيغ مختلفة،
  وJSON داخل شرح وعلامات \`\`\`، ومفاتيح تحاكي أخطاء الخصوصية والمفتاح الخاطئ والحصة؛ ويتحقق من شكل كل طلب
  (مفتاح، سلسلة مجانية تنتهي بالموجّه، بلا حقول Claude، صور data URL).
- أغلفة Word تُفحص ببنية الملف: عدد الأقسام، `w:pgBorders`، وجدول المعلومات.
- المعادلات: المحوّل يُفحص في Node على حالات صعبة وعلى كل معادلات القاعدة ومسائلها (لا «/» بعد التحويل)، وفي المتصفح
  يُتحقق أن الكسور SVG حقيقية (`mfrac`)، وفي Word عدد صور المعادلات أو عناصر `m:oMath` و`m:f`.
- PowerPoint يُفحص بـ python-pptx: الشرائح الأولى والأخيرة، الصور، الجداول، وملاحظات المتحدث.

يعمل الفحص في GitHub Actions بوظيفة مستقلة عن بناء APK.

## 8. قرارات وأسبابها

- **بلا إطار عمل**: نفس نهج المشاريع السابقة؛ واجهة خفيفة وسريعة على الهواتف المتوسطة.
- **المفتاح في الجهاز أو خادم وسيط**: الاستعمال الشخصي لا يحتاج خادمًا؛ والمشاركة تحتاجه حتى لا يتسرب المفتاح.
- **Markdown مقيَّد لا JSON للكتابة**: يسمح بالعرض الحي أثناء التدفق، ومحلّله صغير ومتسامح.
- **صور محفوظة لا روابط**: الروابط الخارجية قد تنكسر أو تُحظر؛ الـ Blob في IndexedDB يُعرض دائمًا ويُضمَّن في Word وPDF.
- **رفض الصورة أفضل من صورة خاطئة**: الصورة غير المؤكدة لا تُوضع، ويُعرض بدلًا منها زر بحث يدوي.
- **Capacitor 7**: نفس بيئة البناء المجرّبة في CI لهذا المستودع (Node 20، JDK 21، Android 35).
