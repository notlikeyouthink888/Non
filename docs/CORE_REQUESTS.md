# طلبات تغيير النواة (`src/core`)

> القاعدة: **وكلاء البناء لا يعدّلون النواة**. يكتبون طلبًا هنا، ويطبّقه وكيل التكامل.
> كل طلب يُسجَّل بحالته: `مطلوب` / `مطبَّق` / `مرفوض`.

| 3 | roads / zoning | `sampleEdge` ببحث ثنائي + شبكة تجزئة للعُقد | المسح الخطي جعل تهيئة المدينة 454 ثانية | ✅ مطبَّق | الجولة 0 |
