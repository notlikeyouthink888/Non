# سياسة الأصول

**كل الأصول في هذا المشروع مولّدة إجرائيًا وقت التشغيل. لا يوجد أي أصل خارجي مُنزَّل.**

| النوع | المصدر | الرخصة |
|---|---|---|
| خرائط PBR (أسفلت، خرسانة، رصيف، عشب، تراب، صخر، رمل، طوب، جص، معدن، قرميد، لحاء، واجهات) | `src/core/textures.js` — ضوضاء Simplex/Worley + اشتقاق خرائط النتوء بـ Sobel | مولّدة ذاتيًا (CC0) |
| خريطة الأرض الكبرى | `src/systems/terrain/macro.js` — خبز من حقل الارتفاعات | مولّدة ذاتيًا (CC0) |
| أسطح الطرق ودهان الخطوط | `src/systems/roads/roadTextures.js` | مولّدة ذاتيًا (CC0) |
| بطاقات أوراق الشجر | `src/core/textures.js#leafCard` | مولّدة ذاتيًا (CC0) |
| هندسة المباني والمركبات والدعائم | `src/systems/*/` — مولّدات إجرائية | مولّدة ذاتيًا (CC0) |
| الصوت | `src/systems/audio` — تخليق WebAudio | مولّد ذاتيًا (CC0) |
| الخطوط | خطوط النظام فقط (`Segoe UI` / `Noto Sans Arabic` / `Tahoma`) | لا تضمين |

## لماذا إجرائي بالكامل؟

1. بيئة التطوير هنا خلف بروكسي يمنع تنزيل حِزَم Poly Haven / ambientCG.
2. التطبيق يعمل **بلا إنترنت** — مطلوب لتغليف الأندرويد.
3. الحجم النهائي صغير (لا صور بايت واحدة في الحزمة).

## ماذا لو أُضيفت أصول خارجية لاحقًا؟

يجب أن تكون **CC0 فقط**، وتُسجَّل هنا بالرابط والرخصة وتاريخ التنزيل قبل الدمج.
