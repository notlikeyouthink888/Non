# Your World

تطبيق أندرويد شخصي بخمسة أقسام — **كل شيء يعمل دون إنترنت**، وكل البيانات تبقى داخل جهازك:
لا حساب، ولا خادم، ولا مزامنة.

| القسم | ما فيه |
|---|---|
| ♪ **الأغاني** | كل أغاني جهازك، تشغيل بالخلفية وعلى شاشة القفل، تكرار وعشوائي، تغيير سرعة التشغيل، ومؤثرات صوتية كاملة |
| ⏰ **الوقت** | مؤقّت وساعة إيقاف، منبّهات بنغمة مخصّصة وتكرار متقدّم، تقويم ومهام، حاسبة نوم، ملخّص نهاية اليوم، وتحذير الاستخدام المطوّل |
| 🎯 **التزاماتي** | ٥٧ تمرينًا وطريقة استرخاء بخطواتها وأفضل وقت لها، ٦ روتينات جاهزة، وتتبّع يومي بالسلاسل |
| 🗺 **الأماكن** | خريطة تعمل بلا إنترنت، أماكن تريد زيارتها بتفاصيلها، مسافة واتجاه من موقعك |
| 📈 **الإنتاجية** | ١٢٤ عنصرًا عمليًا في ١٢ قسمًا، ٦ مسارات مرتّبة، وتتبّع ما أتقنته |

## التشغيل

```bash
npm install          # مرّة واحدة
npm run dev          # معاينة في المتصفّح (http://localhost:5173)
npm run check        # فحص آلي: بناء + تصفّح كل الأقسام + اختبار المسارات
npm run android:sync # بناء + مزامنة مشروع أندرويد
npm run android:apk  # بناء ملف APK (يحتاج Android SDK)
```

في المتصفّح تعمل كل الأقسام، لكن مكتبة الأغاني تصبح باختيار ملفات يدويًا،
والمنبّهات تعمل ما دامت الصفحة مفتوحة. على أندرويد تعمل جميعها أصليًا.

### بناء ملف APK

يحتاج جهازك: Node 20+، JDK 17+، وAndroid SDK (platform 35 + build-tools).

```bash
npm run android:apk
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

> ملاحظة: البناء يتطلّب تنزيل Android SDK وحزم Gradle من خوادم Google،
> لذا نفّذه على جهازك أو في CI يملك هذا الوصول.

## ما الذي يحتاج إنترنت؟ لا شيء تقريبًا

- الأقسام الأربعة الأولى بكاملها تعمل بلا اتصال: المشغّل، المنبّهات، التقويم،
  الالتزامات، الأماكن، المسافات، وشبكة إحداثيات الخريطة تُحسب داخل الجهاز.
- الاستثناء الوحيد وهو **اختياري بالكامل**: زرّ «نزّل خريطة هذه المنطقة» في
  قسم الأماكن يجلب صور الخريطة مرّة واحدة ويخزّنها في جهازك، فتعمل بعدها دون اتصال.
  إن لم تضغطه، لا يخرج أي طلب شبكة من التطبيق أبدًا.
- إذن `INTERNET` في البيان مطلوب لخادم Capacitor المحلي داخل الجهاز نفسه.

## الأذونات ولماذا

| الإذن | السبب |
|---|---|
| `READ_MEDIA_AUDIO` (أو `READ_EXTERNAL_STORAGE` قبل أندرويد 13) | قراءة أغاني جهازك |
| `FOREGROUND_SERVICE` + `..._MEDIA_PLAYBACK` | استمرار التشغيل والشاشة مقفلة |
| `POST_NOTIFICATIONS` | إشعار المشغّل، المنبّهات، التذكيرات |
| `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` | رنين المنبّه في وقته بالضبط |
| `USE_FULL_SCREEN_INTENT` | شاشة المنبّه فوق شاشة القفل |
| `RECEIVE_BOOT_COMPLETED` | إعادة جدولة منبّهاتك بعد إعادة تشغيل الجهاز |
| `ACCESS_FINE_LOCATION` | موقعك في قسم الأماكن (GPS يعمل دون إنترنت) |
| `VIBRATE` / `WAKE_LOCK` / `MODIFY_AUDIO_SETTINGS` | الاهتزاز، إيقاظ الشاشة للمنبّه، ومؤثرات الصوت |

كل الأذونات تُطلب عند الحاجة فقط، والتطبيق يعمل بدون أغلبها مع فقدان الميزة المرتبطة بها.

## بنية المشروع

```
src/
  main.js            نقطة الدخول
  app.js             الشِل: التنقّل بين الأقسام + المشغّل المصغّر
  core/              store, dom, ui, fmt, idb, usage, settings, native (جسر أندرويد)
  sections/
    music/           المكتبة، المشغّل، المؤثرات، شاشة التشغيل
    time/            المؤقّت، المنبّهات، التكرار، التقويم، النوم، ملخّص اليوم
    commit/          الالتزامات والتمارين
    places/          الخريطة والبلاطات والحسابات الجغرافية
    growth/          الإنتاجية
  data/              exercises.js (٥٧) و growth.js (١٢٤)
  styles/            CSS لكل قسم

android/app/src/main/java/com/yourworld/app/
  MainActivity.java
  plugins/           MusicLibrary, Player, Scheduler
  player/            PlayerService (خدمة أمامية + MediaSession + مؤثرات)
  alarm/             AlarmScheduler, AlarmReceiver, AlarmActivity, RepeatRule, BootReceiver
```

التفاصيل المعمارية الكاملة في [`ARCHITECTURE.md`](./ARCHITECTURE.md).

## بياناتك

كل شيء في `localStorage` و `IndexedDB` داخل جهازك. من الإعدادات ⚙ يمكنك
تصدير نسخة احتياطية بصيغة JSON، أو استيرادها، أو مسح كل شيء.

المشروع السابق (لعبة «مدينتي» ثلاثية الأبعاد) محفوظ في مجلّد `legacy/`.
