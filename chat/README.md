# محاورة — Muhawara

**عميل محادثة لأندرويد** يتصل بأي نموذج ذكاء اصطناعي متوافق مع واجهة OpenAI.

التطبيق **وسيط فقط**: لا يفرض أي قيود على المحتوى، ولا يعدّل ما ترسله أو تستلمه،
ولا يرسل أي بيانات لأي جهة عدا نقطة النهاية التي تحدّدها أنت بنفسك.
كل المحادثات والإعدادات محفوظة **على جهازك فقط**.

## الطريقة اللي تعطيك «بلا حدود» فعلاً

### 1. نصّب Ollama على الكمبيوتر
من [ollama.com](https://ollama.com) — ويندوز أو ماك أو لينكس.

### 2. نزّل نموذج
```bash
ollama pull llama3.1:8b        # يحتاج ~8 جيجا رام
ollama pull qwen2.5:14b        # أذكى، يحتاج ~16 جيجا رام
```
تكدر تنزّل أي نموذج من [ollama.com/library](https://ollama.com/library) — بضمنها نماذج
بضبط (fine-tunes) مختلفة تماماً بأسلوبها وحدودها.

### 3. خلّي Ollama يستمع على الشبكة (مو بس على نفسه)

**ويندوز** — بمتغيرات البيئة:
```
OLLAMA_HOST=0.0.0.0
```
ثم أعد تشغيل Ollama.

**لينكس / ماك**:
```bash
OLLAMA_HOST=0.0.0.0 ollama serve
```

### 4. اعرف آيبي الكمبيوتر
```bash
ipconfig        # ويندوز — دوّر على IPv4 Address
ip a            # لينكس
ifconfig        # ماك
```
راح يطلع شي مثل `192.168.1.7`.

### 5. بالتطبيق
افتح **الإعدادات ⚙** → الخدمة: **Ollama** → غيّر نقطة النهاية إلى:
```
http://192.168.1.7:11434/v1
```
واسم النموذج إلى اللي نزّلته. اضغط **اختبار** ثم **حفظ**.

> **شرط:** الموبايل والكمبيوتر لازم على **نفس شبكة الواي فاي**.
> إذا ما اشتغل، تأكد من جدار الحماية (Firewall) على الكمبيوتر يسمح بمنفذ 11434.

## متصفّح النماذج (OpenRouter)

بالإعدادات، زر **⌕** بجانب حقل النموذج يفتح متصفّحاً يجلب قائمة OpenRouter
الحيّة ويعرض لكل نموذج: السعر لكل مليون وحدة، حجم السياق، وشارة **«مجاني»**
للنماذج بلا تكلفة.

**نماذج مقترحة للأدوار والسرد القصصي:**

> إذا تريد مجاني تماماً: افتح المتصفّح واضغط فلتر **«مجانية»** — فيه أكثر من 20 نموذجاً
> بعضها بسياق مليون وحدة.

## تشغيل النموذج داخل الموبايل نفسه (بلا إنترنت)

ممكن — بشرط جهاز قوي. الطريقة: خادم `llama.cpp` داخل **Termux**،
والتطبيق يتصل به على `http://127.0.0.1:8080/v1`.

```bash
# داخل Termux (نصّبه من F-Droid لا من جوجل بلاي)
pkg update && pkg install -y git cmake clang
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp && cmake -B build && cmake --build build -j4

# نزّل نموذجاً — الروابط أدناه مُتحقَّق منها (HTTP 200 + حجم مؤكَّد)
curl -L -o m.gguf "<الرابط من الجدول>"

./build/bin/llama-server -m m.gguf --port 8080 -c 1024 -t 4 --no-warmup
```

**شرح الأعلام المهمة على الهاتف:**

| العلَم | لماذا |
|---|---|
| `-c 1024` | حجم السياق. أصغر = ذاكرة أقل ومعالجة برومبت أسرع بكثير. `-c 4096` على هاتف متوسط يجعل أول رد يتأخر دقائق. |
| `-t 4` | عدد الخيوط. اجعله = عدد الأنوية الكبيرة في معالجك (غالباً 4). |
| `--no-warmup` | يتخطّى تسخيناً أولياً بطيئاً. |

### إذا كان الرد بطيئاً جداً

قِس السرعة من سجل Termux — ابحث عن `tokens per second`:

| السرعة | الحكم | الحل |
|---|---|---|
| أقل من 1 وحدة/ث | غير صالح للاستعمال | النموذج أكبر من طاقة جهازك — انزل لـ 3B أو 1B |
| 1–3 وحدة/ث | بطيء ومزعج | قلّل `-c`، أو انزل لنموذج أصغر |
| 5+ وحدة/ث | مقبول | — |

**السبب الأشيع للبطء الشديد:** النموذج أكبر من الرام المتاحة، فيبدأ النظام
بقراءة أجزائه من التخزين مع كل وحدة (thrashing). الحل الوحيد نموذج أصغر.

> **مهم:** أثناء التوليد **ابقَ داخل التطبيق**. أندرويد يوقف شبكة التطبيقات في الخلفية،
> فإذا بدّلت التطبيق أثناء انتظار رد بطيء سيُلغى الطلب (يظهر في سجل الخادم
> كـ `cancel task`). التطبيق يبقي الشاشة مضاءة أثناء التوليد ويشرح لك السبب إن حدث.

## التحكّم بأسلوب النموذج وحدوده

حقل **تعليمات النظام (System Prompt)** بالإعدادات هو اللي يحدّد شخصية النموذج
وأسلوبه وحدوده. مع النماذج المحلية، هذا الحقل + النموذج اللي تختاره هما
اللي يقرّران المخرجات بالكامل — ماكو طبقة رقابة من التطبيق.

كذلك:
- **Temperature** أعلى = ردود أكثر عشوائية وإبداعاً
- **Top P** يتحكّم بتنوّع الكلمات المختارة
- **عدد الرسائل كسياق** = كم رسالة سابقة تُرسل مع كل طلب (أكثر = ذاكرة أطول لكن أبطأ)

## البناء من المصدر

```bash
npm install
npm run dev          # تطوير على http://localhost:5180
npm run build        # حزمة الإنتاج
npm run android:sync # مزامنة مشروع أندرويد
cd android && ./gradlew assembleDebug
```
الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

## الميزات

- بثّ الرد حرفاً بحرف (SSE)
- محادثات متعددة محفوظة محلياً
- تصدير/استيراد كل المحادثات كملف JSON
- عرض كتل الكود بشكل صحيح (LTR داخل نص عربي)
- جلب قائمة النماذج تلقائياً من الخادم
- زر إيقاف الرد أثناء التوليد
- رسائل أخطاء عربية تشرح سبب فشل الاتصال بدل "Failed to fetch"
- واجهة عربية RTL كاملة، وضع داكن، تعمل بلا إنترنت (عدا الاتصال بالنموذج)

## الخصوصية

- ماكو تتبّع، ماكو تحليلات، ماكو خوادم وسيطة.
- المحادثات في `localStorage` على جهازك.
- مفتاح API يُحفظ على جهازك ويُرسل فقط لنقطة النهاية اللي حدّدتها.
- مع Ollama محلي: **ولا بايت يطلع من شبكتك**.
