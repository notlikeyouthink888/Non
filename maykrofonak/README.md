# مايكرفونك 🎙️

تطبيق أندرويد يحوّل تلفونك إلى **مايك**: وصّل المكبّر بالبلوتوث، اضغط الزر، واحجي —
صوتك يطلع من المكبّر مباشرة.

## التنزيل

**[صفحة نسخ مايكرفونك](https://github.com/notlikeyouthink888/Non/releases?q=maykrofonak&expanded=true)**
— أعلى نسخة بالصفحة هي الأحدث؛ نزّل منها `Maykrofonak.apk`.

افتح الرابط من متصفّح التلفون ← نزّل الملف ← افتحه ← اسمح بـ«التثبيت من مصادر غير معروفة»
إذا طلبها ← ثبّت. النسخ الجديدة تتثبّت فوق القديمة بدون حذف.

يشتغل على أندرويد 8 وأحدث.

## الاستعمال (3 خطوات)

1. شغّل المكبّر ووصّله بالتلفون بالبلوتوث (أو اضغط زر «البلوتوث» داخل التطبيق).
2. افتح مايكرفونك واضغط على المايك الكبير (أول مرّة يطلب إذن المايكروفون).
3. احجي. اضغط مرّة ثانية للإيقاف — أو من الإشعار.

> زر **«🔔 جرّب»** يطلع نغمة قصيرة من المكبّر حتى تتأكد إن الصوت يوصله، وتحت المايك سطر
> يبيّن مستوى صوتك بالمايك وكم يطلع للمكبّر.
>
> إذا ضغطت قبل ما يتصل المكبّر، التطبيق ينتظره ويشتغل وحده أول ما يتصل.
> وتكدر تضغط مطوّلاً على أيقونة التطبيق ← «شغّل المايك» للتشغيل بلمسة وحدة.

## المزايا

| | |
|---|---|
| ⚡ **تأخير قليل** | قراءة المايك بدفعات ≈ 4 ملّي ثانية، والتأخير يبقى ثابت وما يتراكم مع الوقت (تعويض فرق ساعة المايك عن المكبّر) |
| 🔇 **منع الصفير** | يكتشف الصفير (حتى المتقطّع بسبب تأخير البلوتوث) ويطفيه بمرشّح ضيّق بالتردد بالضبط، وصوتك يبقى قوي |
| 🎚️ **مستوى تلقائي** | يرفع الصوت الواطي وينزّل العالي، وما يرفع أبداً إلا بعد سكوت (حتى ما يغذّي الصفير) |
| 🤫 **تنقية الصوت** | يتعلّم ضوضاء الغرفة ويخفّضها لما تسكت |
| 🛡️ **حماية** | محدّد يمنع أي صوت يتجاوز الحد، وإذا انقطع المكبّر يُكتم المايك فوراً (ما يطلع من سماعة التلفون أبداً) ويرجع وحده لما يرجع المكبّر |
| 🎤 **مؤثرات** | طبيعي · صدى · قاعة · خشن · رفيع · راديو |
| 🎵 **كاريوكي** | يشتغل والشاشة مقفلة أو وأنت بيوتيوب، والأغنية تبقى شغّالة مع صوتك |
| 🔒 **خصوصية** | بدون إنترنت أصلاً (ما عنده إذن إنترنت)، ما يسجّل ولا يحفظ شيء، وما يحتاج إذن بلوتوث |

## الأذونات

| الإذن | السبب |
|---|---|
| المايكروفون | حتى ينقل صوتك للمكبّر (الإذن الوحيد اللي ينطلب منك) |
| الإشعارات | إشعار «المايك شغّال» مع زر إيقاف |
| خدمة أمامية (مايكروفون) + منع السكون | يبقى شغّال والشاشة مقفلة |
| تعديل إعدادات الصوت | شريط «صوت المكبّر» داخل التطبيق |

## ملاحظة عن التأخير

البلوتوث نفسه يضيف تأخير (عادة 150–250 ملّي ثانية حسب المكبّر)، وهذا من المكبّر
وما يكدر أي تطبيق يلغيه. التطبيق يضيف فوقه أقل ما يمكن (≈ 40 ملّي ثانية مع البلوتوث،
≈ 20 مع السلك).

## للمطوّرين

تطبيق Java أصلي بدون أي مكتبات خارجية (حجم صغير وتشغيل فوري).

```
app/src/main/java/com/maykrofonak/app/
  MainActivity      الشاشة الوحيدة
  MicButton         الزر الكبير وعدّاد المستوى
  MicService        خدمة أمامية: الإشعار، انقطاع ورجوع المكبّر
  MicEngine         خيط الصوت: AudioRecord ← المعالجة ← AudioTrack
  Speakers          اختيار المكبّر الخارجي (سماعة التلفون ممنوعة)
  Prefs / Params    الإعدادات ونقلها لخيط الصوت

  معالجة الصوت (Java صافية، تنختبر بدون أندرويد):
  VoiceChain        السلسلة كاملة
  HowlGuard         كشف الصفير + مرشّحات قاطعة متكيّفة
  NoiseGate         بوابة ضوضاء تتعلّم مستوى الغرفة
  Leveler           ضبط المستوى التلقائي
  Limiter           محدّد الذروة
  Effects           المؤثرات
  LatencyControl    ثبات التأخير
  DriftResampler    تعويض فرق الساعات
```

```bash
cd maykrofonak
./gradlew testDebugUnitTest   # اختبارات المعالجة (تشمل حلقة صفير كاملة بتأخير بلوتوث)
./gradlew assembleRelease     # الناتج: app/build/outputs/apk/release/app-release.apk
```

يحتاج JDK 17+ وAndroid SDK (platform 35). كل دفعة على الفرع تبني APK تلقائياً عبر
GitHub Actions وتنشره في إصدار جديد باسم `maykrofonak-b<رقم البناء>-<المحاولة>`
(إصدارات هذا المستودع ثابتة ما تنحذف، فكل بناء ياخذ وسم جديد).

مفتاح التوقيع في `keystore/` مخصّص للتثبيت الشخصي حتى تتثبّت النسخ فوق بعض؛
للنشر على Google Play استعمل مفتاحاً خاصاً غير منشور.
